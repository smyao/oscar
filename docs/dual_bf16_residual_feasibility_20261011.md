# 双 BF16 残差、三项补偿：只读筛选（2026-10-11）

**状态：已提出、现有证据审查完成；暂缓，不入组合、不写核。** 直接三次完整 Matmul 拼接已无速度依据；未知融合实现尚无精度资格和足够大的完整净收益证据。未运行新实验，未修改精度或生产路径。档案 #148/#154 与 D.4继续约束模型精度、异步生命周期和有界工作区。

**方案与精度边界。** 对每个FP32输入设 `xh=BF16(x)`、`xl=BF16(x−FP32(xh))`，两侧均分解，再计算 `XhYh + XhYl + XlYh`，三项均FP32累加。它遗漏 `XlYl` 和残差再次舍入的误差；即使加第四项，也未自动消除表示误差及新的累加舍入。将三次点积再相加，或在每个K128内串行加入三项，均改变原FP32乘积/累加链；不能把它声明为保持原逐输出数学顺序的布局变换。

在RNE、正常数且无溢出/下溢的假设下，BF16单位舍入误差 `u=2^-8`，两分量表示及遗漏低×低项的误差量级为 `O(u²)`；点积绝对误差仍受 `Σ|xk·yk|` 控制，抵消时没有统一的小相对误差保证。FP32有限极大值、subnormal、signed-zero/nonfinite和原错误优先级也不在该简化界内。必须对实际可达域独立论证，不能改oracle、放宽冻结门或新增静默单cast路径。

**不能直接单cast。** [已有有限值反例](../reports/single_bf16_cast_counterexample_20261009.json) 中，INT2可表示的K为1和1.0029296875，单BF16 cast均变1；FP32累加也救不回丢失输入，输出误差0.092667超过当点冻结门0.007963。[已存prefill压力报告](../reports/prefill_tile_stress_20260930.json) 有7个可由store到达的失败，且存在LSE过而输出失败。这些否定无条件单cast/已有dtype替换，**并不证明三项方案已失败**；两分量甚至可能修复该特定单cast反例，但尚无它自身的完整精度证据。

**现成速度证据只支持筛掉直接拼接。** [同形完整任务结果](../reports/fp32_bf16_mmad_ratio_20261010/decision.json) 为QK24 `19890→16399` ticks（1.212879倍），PV126 `34758→26214`（1.325933倍）。[微核源码](../csrc/experiments/fp32_bf16_mmad_ratio/kernel.cpp) 是单次Matmul、basic64/64/128、HF32关闭；输入本身可被BF16精确表示，没有残差分解或三项重组。若简单复用三次完整BF16调用，条件成本已为49197/78642 ticks，约为原FP32的2.47/2.26倍，尚未加producer与重组；这不是三项方案的新测量。个别MMAD驻留277→85、533→149含流水等待，不能求和成wall、当dtype峰值或取代完整分母。

**融合方案必须跨过的门槛。** 设当前关键路径上可替换的纯计算成本为C，同工作量下可持续的BF16/FP32计算率比为r，额外暴露的分解、重组、同步成本为E；即使其他成本不变，也需 `3C/r+E<C`，即 `r>3/(1−E/C)`（E<C）。当前完整任务1.213/1.326不能当r，项目也没有可填入的已测大batch r。完整step还须核HBM/L2字节、Vector/Scalar、launch/sync及依赖路径，不能以“变成memory-bound”代替减少step time。

**流量与空间不能按单BF16减半。** 两份BF16合计仍为4B/输入值，等于原FP32；无复用的三项消费者会合计读取每操作数6B/值，另有cast回FP32、减残差、再次cast、NZ布局和事件成本。若三份FP32部分积落GM，再读回合并，输出阶段是三写三读加一写，约28B/输出元素，相比单份4B显著增加；共用L0C可避免这部分GM流量，但必须证明容量、调度、累加和完成协议。上述是逻辑搬运账，真实HBM与L2命中分开计；不得把host预分解或免费packing藏在分母外。持久INT2压缩率不会因此再提升，新增workspace反而可能减少可驻留batch；MTP全部轮次的分解/计算/流量也须除以实际有效输出量核算。

**重开条件：** 独立精度论证覆盖冻结的实际可达域，且一个明确的融合数据流在真实producer、三项计算、重组和同步都计入后，仍有明显完整算子/step净贡献，才值得研究。只有dtype峰值、单cast通过样本、消除某次转换或1–5%小增量，均不重开。当前结论是证据与净收益不足，不能写成已证明所有多分量算法不可行。
